Cloud storage services provide the ability to store documents and files online. FX currently supports the following cloud storage services:

  • Box (Box.net)
  • Dropbox
  • Google Drive
  • Microsoft OneDrive (formerly SkyDrive)
  • OwnCloud (using WebDAV)
  • SugarSync

Creating Connections

NOTE: Before you create a cloud service connection, you'll need to have an account with a cloud service.

To create a new cloud service connection, first go to the home screen and select the "Cloud Storage" catalog. Open the "+" menu and tap on the type of cloud service you would like to connect to, e.g. "Google Drive", or "Dropbox". Directions will then be provided to register FX with the cloud service. In many cases you will then be directed to a web page on the cloud service itself where you will enter your username and password information.

Notes about OneDrive (formerly SkyDrive)

Please also be aware that FX will NOT retrieve any personal / social / contact information from your OneDrive account. OneDrive requires applications to request such permissions from the user, even if the application has no use for them.

Troubleshooting

If you're not able to connect to a cloud service, try first connecting to that service using a web browser to make certain the service is available and that your account is working properly.

Even if you're able to connect to the web site, cloud services do experience momentary outages where third-party applications will be unable connect. Try waiting a few minutes and connecting again.

Pay close attention to what the service is requesting for your "user name". Some services will want you to enter your full email address, while others will ask for a "user name" that you specified when you originally created your account.
