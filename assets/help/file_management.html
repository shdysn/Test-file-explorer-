Navigating Folders

Navigating folders with FX is similar to doing so on a desktop PC using Windows Explorer or MacOS Finder. Simply touch a folder or file to open it.

To navigate backward to the previous level folder, either tap the device's "Back" button or use the Location Bar "breadcrumb" view at the top of the screen.

To perform an operation on one or more files, first select them by long pressing on an item or tapping the [+] button in the bar at the top of the screen. The menu will change to show options relevant to the selection. More options are available when only one item is selected. See the Selection Documentation for a more thorough description.

Deleting Files and Folders

Select one or more files to delete, and tap the "Delete" option which appears at the top of the screen. A confirmation dialog will appear showing you a list of the files which are about to be deleted. If you are sure you want to delete the files, tap the confirmation checkbox and then the "OK" button.

Renaming Files and Folders

Select a single file. You can then tap the edit icon (pen) adjacent the item's name shown in the top bar of the screen. A rename option is also available in the upper-right menu when a single file is selected. Enter a new file name and tap "OK".

Copying and Moving Files and Folders

To copy or move files, first go to the directory containing the files you want to copy or move and select them. In the menu bar, select "Cut" if you would like to move the files or "Copy" if you want to copy them. A "Clipboard" banner will appear at the top of the screen indicating that items have been cut or copied to clipboard.

Once you have placed files on the clipboard, navigate to the folder where you would like them to be moved or copied. Tap the "Clipboard" banner at the top of the screen and select "Paste". The files will be pasted into the directory.

If you decide you do not want to copy/move the files, you can open the clipboard by tapping the "Clipboard" banner at the top of the screen and then tapping "Clear".

Creating New Folders

To create a new folder, open the main menu and select "New Folder". Enter a name for the folder and press the "OK" button.

Creating New Files and Documents

To create a file, open main menu and select "New File". Select the type of file first, e.g., "Empty", "Plain Text", or "Microsoft Word Document". Then enter a name and press the "OK" button.

Sending Files via E-Mail

To send a file by e-mail, select it, open the menu and choose "Share". Tap the appropriate e-mail app.

Sending Files via Bluetooth

To send files by Bluetooth, select them, open the menu and choose "Share". Tap the "Bluetooth" option. Select the device you want to send the file to.

In order to send a file using Bluetooth, your device and the recipient device will need to be "paired." The receiving device will need to support receiving "pushed" files over Bluetooth and it must be ready to receive such files. See the Bluetooth section for more information on "pairing" devices together.

Hidden Files

On Android, any files whose name starts with a period (.) is considered by the operating system to be hidden. By default, FX will not show hidden files when browsing through folders. If you want to see hidden files, open the view menu and tap "Show Hidden". When you want to again hide hidden files, simply repeat the process.

Sorting Files

You can change the sort order of files by tapping the View menu and selecting one of the options under "Sort By". To sort files in reverse order, press-and-hold an option under the "Sort By" heading. You can save sort orders for individual folders using the "Save" option.
