The home screen of FX displays the top-level file, media, and network "catalogs" available on your device. Tap on a catalog to open it.

File Catalogs {All Versions}

  • Main Storage: "Main Storage" is a phone/device's internal storage area for your personal files and media.
  • Media Card: On devices with installed SD Cards or connected USB storage devices, "Media Card" items may be shown.
  • System: The read-only "system" catalog is the internal file system of your Android device.
  • System (Root): This version of the system catalog provides root access to the device's internal filesystem. It will only be present if your device supports root access and you have the root access option enabled in FX.

Media Catalogs {FX+}

  • Images: The image catalog indexes all photos and images on your device.
  • Videos: The video catalog indexes all videos on your device.
  • Music / Audio: The music catalog allows you to browse your audio files organized by Artist, Album, Track, and/or Playlist. Playlists can be created, updated, and deleted by using the music catalog.
  • Apps: The apps catalog is used to manage applications installed on your device. You can manage installed user apps, system apps, or browse apps based on the permissions they require.

Network Catalogs {FX+}

  • Network: The Network catalog enables you to connect to network computers and servers, including:
    • SMB (Windows) network shares
    • FTP servers (including secure FTP, i.e., FTP-S and FTP-ES)
    • WebDAV servers
    • SSH (Secure Shell) hosts
  • Cloud Storage: The Cloud Storage catalog is used to access online cloud storage services, including:
    • Box
    • Dropbox
    • Google Drive
    • Microsoft OneDrive
    • OwnCloud
    • SugarSync
  • Bluetooth: Browse paired Bluetooth devices and transfer files to/from devices that support Bluetooth FTP. See the Bluetooth section for more information.
  • Web Access: Use FX remotely from a desktop computer's web browser on your Wi-Fi network. See the Web Access section for more information.
  • FX Connect: FX Connect provides direct file transfer between two devices running FX. See the FX Connect section for more information.

Utilities {All Versions}

  • Recent: The "Recent" section provides quick access to recently updated files on your device.
  • Cleaning Tools: The "Cleaning Tools" section enables browsing the filesystem while showing "deep" directory sizes, so you can see the file/folder counts and total size of any directory. It also offers the ability to show all large files and search for and remove duplicate files.
