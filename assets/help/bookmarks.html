You can create bookmarks to commonly used folders which will then appear at the top of the FX "Home Screen".

To create a bookmark, first visit the folder which contains the folder you want to bookmark. For example, if you want to bookmark the "Music" folder, open the "Main Storage" catalog on the home screen. Then tap-and-hold on the "Music" folder to select it. In the upper right menu, tap the "Bookmark" icon. If you then navigate back to the home screen, you will see the bookmark at the top of the screen.

You can rename, rearrange, remove, and edit bookmarks. To do so, tap-and-hold on the bookmark on the FX home screen.

When opened from the home screen, a bookmarked folder will behave as though it is its own file catalog. That is, opening a bookmark and then pressing the "Back" button will take you back to the home screen, not the bookmark's parent folder.
