Web Access enables you to access, manage, and transfer content to/from your device through a desktop computer's web browser. The Android device and computer must be connected to the same Wi-Fi network.

Starting Web Access

To start Web Access, tap the start button on the "Web Access" screen. When started, a URL will be displayed that you can type into your computer's web browser. Enter the provided password to log in to the device.

Using Web Access

Once you've logged in, you can access the files and media on the device by clicking the "FILES", "MUSIC", "IMAGES", and "VIDEOS" tabs in the web browser.

Click once on items to select them, or double-click to open them. Right clicking on items will often present a context menu providing additional options. You can also explore the menu toward the upper-left of the screen to perform additional actions.

Uploading Files

Files can be uploaded to a device in the "FILES" and "MUSIC" sections by dragging and dropping them into the web browser. Users of modern browsers such as Firefox and Chrome may upload entire folders or hierarchies of folders by drag-and-drop.

Stopping Web Access

When you have finished using Web Access, turn it off by tapping the stop button on the Web Access screen on your device.
