You can use FX to connect to networked computers and servers using Windows Networking (SMB), File Transfer Protocol (FTP), Secure Shell file transfer protocol (SFTP), and WebDAV.

Creating Connection Bookmarks

To create a new connection bookmark, first go to the home screen and select the "Network" catalog. Then open the "+" menu and tap on the type of connection you want to create, i.e., a Windows/SMB connection, FTP server connection, SSH FTP server connection, or WebDAV connection.

Authentication Types

  • Ask for password each time: you will be prompted to enter a password each time you want to connect to the host. This option avoids storing the password in any form on your mobile device, but can be undesirable if you must enter the password in public places.
  • Encrypt password in keyring: the password will be stored in an encrypted form in your keyring. To connect to the host, you will be required to enter only your keyring password.
  • Store password without encryption: the password will be stored in plain-text form in the password database. This option is of course not recommended for accessing any critical systems.
  • No password required: the host does not require a password.
