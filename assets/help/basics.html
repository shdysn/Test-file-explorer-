The User Interface

  • The majority of the screen, the "work area" is used to display whatever you're working on. Typically this is a list of files, photos, music tracks, or network locations.
  • The "location bar" at the top shows you where you are and where you've been. You can drag it left and right when its content is wider than the screen. Tapping a previous location in the location bar will take you there.
  • The menu, above / to the right of the location bar, provides access to various features that operate on the items displayed in the work area. The "main" menu in the upper right corner (displayed as three dots) contains general options.
  • The drawer menu at the top left of the screen lets you open, close, and switch windows, manage background tasks, and access general features such as the application settings and help.

Selecting Items

There are several ways to start selecting items in FX:

  1. Long-press on an item.
  2. Tap the [+] button in the menu bar.
  3. Drag your finger horizontally across an item.

Tap additional items to select or de-select them. You can also long-press to select all items between an item and the one you previously selected.

Once one or more items have been selected, the menu bar will change to display a list of actions you can perform with those items. For example, on most screens, a "copy" option will appear, allowing you to copy the selected items to the clipboard.

After you perform an action on the selected items using the menu, the menu bar will return to its normal state. If you want to exit "selection mode" without performing any action, tap the "X" in the upper-left corner of the menu.

Menus

The main menu (three dots) in the upper right corner of the screen can be used to perform actions on the content displayed below. For example, when viewing a list of files, you can you can tap the main menu and press "New Folder" to add a new folder.

Pinching to Zoom

Zooming in or out enables you to choose between seeing more information about individual items or seeing more items at the same time. To adjust the zoom level, first place two fingers on the screen, then pinch them together to zoom out, or spread them apart to zoom in. When zoomed in, some screens will show additional information about each item.

Themes

You can change the appearance of the entire user interface of FX using themes. To change the current theme, tap the main menu and then "Settings".
