Using the Text Editor

FX provides both a read-only text editor and a text viewer. You may need to long press on a file and select "Open With" in order to open it with FX TextEdit. If you are using the text viewer and wish to edit a file, there is an option in the action bar to open it directly.

Cut and Paste

Cut and paste can be used to reorder lines/paragraphs within a file, duplicate content within a file, or copy/move content from one file to another. To use cut and paste, simply tap and hold on text within the file. You can then drag the beginning/ending text markers to select an area of text. Tap cut or copy to place the text on the clipboard. "Cut" will remove the text from the document, whereas "Copy" will leave it intact. To paste the text, you can either tap and hold at the desired location and select "Paste", or move the cursor to the desired location, tap the "Edit" menu, and then select "Paste".

Undo / History

To undo a change made to a file, tap the "Edit" menu and then "Undo / Redo". A toolbar will appear showing undo and redo options. These features may also be accessed via Ctrl+Z (Undo) and Ctrl+Y (Redo) on keyboard-equipped devices. You can undo multiple changes by repeatedly invoking the "Undo" option.

Search

To find text within a file, tap the "Edit" menu and select "Search". Enter the text you would like to search for in the text box at the top of the screen. Use the left and right arrow buttons adjacent the search box to find the previous and next occurrences of the text. The search will wrap around when it reaches the end (or beginning) of the file.

Keyboard Shortcuts

If your device has a physical keyboard, or if a keyboard has been connected to it, the following shortcuts can be used. All keyboard shortcuts listed here may also be accessed using the menu.

On devices without a Control or "Ctrl" key (e.g. Motorola Droid phones with physical keyboards), these shortcuts may be accessible by holding down the "Menu" button and then pressing the corresponding letter.

Manipulating Text
Shift+Arrows Select text from cursor position.
Ctrl+A Select all text.
Ctrl+X Cut the selected text to the clipboard.
Ctrl+C Copy the selected text to the clipboard.
Ctrl+V Paste the contents of the clipboard at the cursor position.
Navigation and Search
Ctrl+F Find text within the file.
Ctrl+L Go to a specific line number.
Ctrl+I Display information / details about the current file.
Undo / History
Ctrl+Z Undo last changes.
Ctrl+Y Redo last undone changes.
File Commands
Ctrl+N Create a new file.
Ctrl+O Open a file.
Ctrl+S Save changes to the file.
